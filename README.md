# Sentiment Scope

Sentiment Scope is a Python-based sentiment analysis web application that analyzes customer reviews and classifies them as Positive, Neutral, or Negative.

## Overview

The project uses Natural Language Processing (NLP) to analyze customer review text and calculate a sentiment score.

Users can enter their own review into the web application and receive an immediate sentiment classification.

The application also analyzes a CSV dataset and provides dashboard statistics.

## Features

- Analyze individual customer reviews
- Positive, Neutral, and Negative classification
- Sentiment scoring
- Dataset analysis
- Review statistics
- Average sentiment score
- Recent review table
- CSV data processing
- Flask web interface
- Responsive design
